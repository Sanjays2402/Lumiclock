# 🕐 Lumiclock

![JavaScript](https://img.shields.io/badge/Vanilla_JS-ES6+-F7DF1E?style=flat&logo=javascript&logoColor=black)
![Vite](https://img.shields.io/badge/Vite-6-646CFF?style=flat&logo=vite&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-Custom_Properties-1572B6?style=flat&logo=css3&logoColor=white)

A fullscreen immersive **analog clock** with a stunning time-of-day adaptive background. The ambient colors shift smoothly through phases — midnight, dawn, midday, sunset, and evening — creating a living, breathing clock experience.

## ✨ Features

- 🌅 **Time-aware ambient lighting** — background colors morph based on the current hour
- 🎨 **6-blob gradient mesh** — rich, layered radial gradients for a lush backdrop
- 🕰️ **Smooth analog hands** — hour, minute, and second hands with CSS transforms
- 🌙 **5 color phases** — midnight → dawn → midday → sunset → evening with seamless interpolation
- 📱 **Fullscreen immersive** — no chrome, just the clock
- ⚡ **Zero dependencies** — vanilla HTML, CSS, and JavaScript

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Sanjays2402/Lumiclock.git
cd Lumiclock

# Install dependencies
npm install

# Start dev server
npm run dev
```

## 📦 Build

```bash
npm run build
npm run preview
```

## 🏗️ Project Structure

```
Lumiclock/
```
